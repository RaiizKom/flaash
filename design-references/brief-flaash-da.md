# Brief direction artistique — Flaash

## Contexte du produit

Flaash est une web app d’appareil photo jetable digital pour événements.

Le principe est simple :

1. L’organisateur crée un événement.
2. Flaash génère un lien et un QR code.
3. Les invités scannent le QR code.
4. Ils prennent des photos depuis leur téléphone, sans installer d’application.
5. Les photos restent cachées pendant l’événement.
6. La galerie est révélée plus tard, au moment choisi.
7. Les souvenirs peuvent être consultés, partagés et exportés.

Flaash s’adresse principalement aux mariages, anniversaires, soirées privées, événements premium accessibles et agences événementielles.

Le produit doit donner envie de vivre une expérience collective, spontanée et émotionnelle, pas seulement d’utiliser un outil technique.

---

## État actuel de la marque

La marque actuelle Flaash possède déjà une base intéressante :

* logo serif élégant ;
* palette cream / ink / amber / forest ;
* ambiance premium ;
* interface simple ;
* expérience invité claire ;
* concept fort autour du QR code, de la capture photo et de la révélation différée.

Cependant, la direction actuelle paraît parfois trop :

* luxueuse ;
* exclusive ;
* sérieuse ;
* privée ;
* statique ;
* proche d’une invitation de mariage premium ;
* trop éloignée de l’énergie réelle d’une soirée.

Le risque est que Flaash donne l’impression d’un produit beau mais un peu froid, alors que le concept doit transmettre de la vie, du mouvement, de la spontanéité et des souvenirs.

---

## Nouvelle direction souhaitée

La nouvelle direction doit conserver l’élégance de Flaash, mais ajouter une dimension plus vivante, chaude, sociale, analogique et immersive.

L’objectif est de passer de :

**Premium exclusif**

vers :

**Premium vivant, chaleureux et social**

La nouvelle DA doit faire ressentir :

* la chaleur d’une vraie soirée ;
* l’énergie des invités ;
* le côté spontané des photos prises par les proches ;
* la nostalgie d’un appareil photo jetable ;
* le plaisir de découvrir les souvenirs plus tard ;
* la simplicité d’un QR code ;
* le côté collectif de l’expérience.

Flaash ne doit pas ressembler à un SaaS corporate, ni à une marque de luxe froide. Flaash doit ressembler à une expérience événementielle désirable, humaine et facile à adopter.

---

## Inspiration principale

Les références Lapoint Surf Camp sont utilisées pour leur direction artistique, pas pour leur sujet.

Ce qu’il faut reprendre de cette inspiration :

* fonds crème chauds ;
* boutons rouges très visibles ;
* rouge qui évoque un bouton d’appareil photo ou un déclencheur ;
* gros titres impactants ;
* mise en page éditoriale ;
* photos immersives avec grain ;
* ambiance solaire, humaine et vivante ;
* cartes arrondies ;
* sections aérées ;
* rythme visuel fort ;
* impression de voyage, de souvenir et de communauté.

Ce qu’il ne faut pas reprendre :

* l’univers surf ;
* les contenus liés au voyage ou aux camps ;
* le vocabulaire de réservation touristique ;
* le style exact des pages ;
* la typographie exacte ;
* les mêmes layouts copiés ;
* les mêmes compositions de cartes ;
* le bandeau promotionnel copié tel quel.

Il faut adapter cette vibe au monde des événements : mariages, anniversaires, soirées privées, fêtes, moments entre amis, événements élégants mais accessibles.

---

## Positionnement visuel cible

La direction cible peut être résumée ainsi :

**Flaash — analog social premium**

Mots-clés :

* vivant ;
* chaleureux ;
* analogique ;
* social ;
* spontané ;
* émotionnel ;
* européen ;
* simple ;
* mémorable ;
* premium mais accessible ;
* pas trop parfait ;
* pas trop luxe ;
* pas trop SaaS.

L’ambiance doit rappeler une photo de soirée prise sur pellicule ou appareil jetable, mais présentée dans un site moderne, clair et désirable.

---

## Palette recommandée

La palette actuelle doit être conservée, mais la hiérarchie doit évoluer.

Couleurs principales :

* Cream : `#FAF7F2`
* Cream deep : `#EFE8DA`
* Ink : `#1A1A1A`
* Shutter red : `#FF332D`
* Amber : `#E07B2E`
* Forest : `#1E3D2F`
* Muted : `#756F68`

Rôles recommandés :

* Cream : fond principal du site.
* Ink : titres, textes forts, footer, sections sombres.
* Shutter red : CTA principal, boutons, actions importantes, rappel du bouton d’appareil photo.
* Amber : chaleur, accents secondaires, détails émotionnels.
* Forest : raffinement, détails événementiels, badges secondaires.
* Muted : textes secondaires, sous-titres, descriptions.

Le rouge ne doit pas donner une impression agressive. Il doit être utilisé comme un signal d’action : prendre une photo, créer un événement, révéler la galerie, voir les souvenirs.

---

## Typographie

Le logo Flaash en serif doit être conservé.

Cependant, la landing page peut évoluer vers une hiérarchie typographique plus vivante :

* Logo : serif élégant Flaash.
* Gros titres : typographie très impactante, bold, expressive, plus directe.
* Labels : uppercase, letter-spacing, style éditorial.
* Corps de texte : sans-serif lisible, naturel, moderne.
* CTA : uppercase, bold, clair, avec forte présence visuelle.

La typographie doit éviter un rendu trop luxe ou trop institutionnel. Elle doit rester premium, mais avec plus d’énergie.

---

## Style des boutons

Les boutons deviennent un élément fort de la marque.

Bouton principal :

* rouge shutter-red ;
* très arrondi ;
* généreux ;
* texte uppercase ;
* impression de bouton d’appareil photo ;
* fort contraste ;
* utilisé pour les actions principales.

Exemples :

* Créer un événement
* Commencer
* Voir la galerie
* Prendre une photo

Bouton secondaire :

* fond ink ;
* texte cream ;
* arrondi ;
* utilisé pour les actions importantes mais moins émotionnelles.

Bouton ghost :

* transparent ;
* bordure ink ou cream selon le fond ;
* utilisé pour les actions secondaires.

## Style des images

Les images doivent être centrales dans la nouvelle DA.

Style recherché :

* photo éditoriale ;
* grain analogique ;
* chaleur ;
* lumière de soirée ;
* flash doux ;
* candid ;
* mouvement léger ;
* cadrages imparfaits ;
* personnes naturelles ;
* émotion réelle ;
* ambiance européenne ;
* moments vécus plutôt que photos posées.

À éviter :

* images IA trop parfaites ;
* visages trop lisses ;
* sourires trop stock-photo ;
* mariages trop luxueux ;
* tables trop parfaites ;
* scènes trop cinématographiques ;
* smartphones trop mis en avant ;
* fausses interfaces d’application ;
* textes lisibles sur les écrans ;
* logos ;
* compositions trop corporate.

Les images doivent donner l’impression de vrais souvenirs capturés pendant une soirée.

---

## Images nécessaires pour la landing

La landing doit idéalement utiliser 3 à 4 types d’images.

### Image 1 — image hero

Objectif : faire ressentir l’énergie de Flaash.

Sujet recommandé :
Un groupe d’amis ou d’invités à une soirée, ambiance chaude, quelqu’un prend une photo, rires naturels, lumière de soirée, cadrage vivant.

Le téléphone peut être présent, mais ne doit pas dominer l’image.

### Image 2 — scan QR

Objectif : expliquer simplement l’usage.

Sujet recommandé :
Une carte QR sur une table d’événement, avec une main tenant un téléphone à proximité. Décor : verre, bougie, fleurs, nappe, traces de soirée.

Le QR doit être visible mais sans URL ni texte lisible.

### Image 3 — capture

Objectif : montrer les invités en train de capturer des moments.

Sujet recommandé :
Une personne prend une photo pendant une soirée, avec d’autres invités qui rient ou bougent. Ambiance spontanée, flash doux, grain.

### Image 4 — reveal

Objectif : vendre l’émotion de la révélation.

Sujet recommandé :
Petit groupe assis ensemble après l’événement, regardant des photos sur un smartphone. Émotion naturelle, nostalgie, sourires calmes, chaleur.

L’écran du téléphone ne doit contenir aucun texte lisible ni fausse UI.

## Structure recommandée pour la landing

La landing page devrait être refondue avec une structure plus éditoriale et immersive.

### 1. Navbar

Simple, claire, avec logo Flaash, liens principaux et CTA rouge.

### 2. Hero éditorial

Objectif :
Comprendre immédiatement le produit et ressentir l’ambiance.

Structure possible :

* grand titre fort ;
* sous-texte court ;
* CTA rouge ;
* CTA secondaire ;
* grande image lifestyle grainée ;
* fond cream.

Exemples de titres possibles :

* L’appareil photo jetable de vos événements.
* Les photos que personne n’avait prévues.
* Vos invités capturent la soirée. Flaash révèle les souvenirs.
* Un QR code. Des photos. Une galerie révélée plus tard.

### 3. Bande d’arguments courts

Exemples :

* Zéro app à installer
* QR code inclus
* Reveal différé
* Galerie partagée
* Export ZIP
* Hébergé en Europe

### 4. Comment ça marche

Quatre étapes simples :

1. Créez votre événement
2. Partagez le QR code
3. Les invités capturent
4. Révélez la galerie

Le ton doit être simple, humain et visuel.

### 5. Section immersive avec grille d’images

Objectif :
Faire ressentir l’expérience.

Utiliser une grille asymétrique avec images lifestyle, cartes arrondies, légendes courtes et rythme visuel.

### 6. Section révélation

Section émotionnelle centrale.

Possibilité de fond ink ou image sombre avec overlay.

Message à transmettre :
Pendant l’événement, les photos restent cachées. Au moment choisi, la galerie s’ouvre. Tout le monde redécouvre la soirée à travers les yeux des invités.

### 7. Types d’événements

Mariages, anniversaires, soirées privées, événements d’entreprise, agences événementielles.

À traiter avec des cartes simples et visuelles.

### 8. Tarifs

Simple, clair, pas trop SaaS.

Le pricing doit être rassurant, mais l’émotion doit rester dominante.

### 9. FAQ

Claire, utile, sobre.

### 10. CTA final

Très émotionnel et direct.

Exemples :

* Créez votre premier événement Flaash
* Préparez les souvenirs avant la soirée
* Lancez votre galerie privée

### 11. Footer

Sobre, fond ink ou cream deep.

---

## Ton rédactionnel

Le ton doit être :

* simple ;
* chaleureux ;
* direct ;
* vivant ;
* premium sans être pompeux ;
* émotionnel sans être dramatique ;
* accessible.

À éviter :

* vocabulaire trop luxe ;
* phrases trop abstraites ;
* jargon technique ;
* ton SaaS B2B ;
* promesses trop marketing ;
* wording trop mariage exclusivement.

Exemples de ton souhaité :

* Vos invités scannent. Ils capturent. Vous révélez les souvenirs.
* Les photos restent cachées jusqu’au moment choisi.
* Pas d’app à installer. Juste un QR code à scanner.
* Une galerie commune, remplie par ceux qui ont vraiment vécu la soirée.
* Redécouvrez votre événement à travers les yeux de vos invités.

---

## Ce qu’il faut absolument éviter

Ne pas transformer Flaash en :

* site de surf camp ;
* site de voyage ;
* marque de luxe froide ;
* SaaS corporate ;
* app gadget ;
* réseau social ;
* photobooth classique ;
* clone du site Lapoint.

Ne pas utiliser :

* fausse UI visible sur les téléphones ;
* textes lisibles générés par IA ;
* logos inventés ;
* images trop parfaites ;
* photos de mariage trop luxueuses ;
* visages trop proches ;
* compositions trop posées ;
* promesses trop compliquées.

---

## Direction finale attendue

La nouvelle landing Flaash doit donner cette impression :

“J’ai envie d’avoir ça à ma soirée.”

Elle doit être claire sur le produit, mais surtout donner envie de vivre l’expérience.

Flaash doit vendre :

* une ambiance ;
* des souvenirs ;
* une surprise ;
* un moment collectif ;
* une simplicité d’usage.

Le produit est technique, mais la landing doit vendre l’émotion.
