# Flaash campaign rules

Statut : règles de campagne et d'application de marque pour Flaash.

Direction : **Analog Social Premium**.

## 1. Principe

Flaash doit se comporter comme une vraie marque sur chaque support.

Une vraie marque ne répète pas seulement un logo. Elle répète :

- une vérité ;
- une tension ;
- des gestes ;
- des objets distinctifs ;
- un ton ;
- une hiérarchie visuelle ;
- une manière reconnaissable de montrer le monde.

Pour Flaash, tout revient à :

> Vivre maintenant. Capturer sans interrompre. Révéler plus tard. Revoir ensemble.

## 2. Séquence rituelle Flaash

La séquence officielle :

1. Créer l'événement.
2. Poser ou partager le QR.
3. Les invités scannent.
4. Ils capturent sans installer d'app.
5. Les photos restent cachées.
6. Le reveal arrive.
7. La galerie devient mémoire collective.
8. Les souvenirs s'exportent.

Toute campagne doit renforcer au moins une étape et, idéalement, faire sentir la séquence complète.

## 3. Règles de campagne

- Chaque campagne doit avoir une idée.
- Chaque image doit avoir un rôle.
- Chaque caption doit porter une tension.
- Chaque carousel doit raconter une mini-séquence.
- Chaque support doit répéter les distinctive assets.
- Le rouge doit rester un signal d'action.
- Le téléphone ne doit jamais devenir le héros.
- Le QR doit être un objet social.
- Le reveal doit être traité comme un moment de marque.
- L'analogique doit rester une texture émotionnelle, pas un déguisement vintage.
- Le premium doit exprimer le soin, pas le prestige.

## 4. Formats de campagne possibles

### Les photos attendent. La soirée, non.

Angle : protéger la présence pendant l'événement.

Images :

- soirée en train de se vivre ;
- téléphone périphérique ;
- photos cachées ;
- reveal annoncé.

### Une soirée. Tous les regards.

Angle : mémoire collective.

Images :

- plusieurs points de vue ;
- invités différents ;
- galerie vivante ;
- détails imparfaits.

### Le reveal commence.

Angle : moment de retour.

Images :

- petit groupe autour d'un téléphone ;
- réactions ;
- fond Ink ;
- phrase courte.

### Pas une app. Un rituel.

Angle : différenciation.

Images :

- QR card ;
- bouton rouge ;
- compteur ;
- photos cachées ;
- reveal.

### Ce que les invités ont vu.

Angle : regard collectif.

Images :

- angles imparfaits ;
- détails de soirée ;
- rires ;
- moments non officiels.

### Le lendemain de la soirée.

Angle : redécouverte.

Images :

- lumière de fenêtre ;
- groupe calme ;
- galerie qui s'ouvre ;
- souvenirs qui reviennent.

### Avant le reveal.

Angle : attente.

Images :

- photos cachées ;
- compteur ;
- écran sobre ;
- tension courte.

### Après le reveal.

Angle : mémoire retrouvée.

Images :

- galerie ;
- export ;
- réactions ;
- album vivant.

## 5. Landing page

Rôle : faire comprendre le rituel complet.

Règles :

- ouvrir sur la soirée vécue ;
- ne pas commencer par la fonctionnalité ;
- montrer scan, capture, attente, reveal dans cet ordre ;
- faire du reveal le sommet émotionnel ;
- garder pricing et FAQ comme preuves rassurantes ;
- répéter les distinctive assets sans surcharge.

À éviter :

- landing SaaS à grilles de features ;
- hero téléphone ;
- promesse trop fonctionnelle ;
- ton mariage luxe ;
- image décorative sans rôle.

## 6. Hero

Rôle : vendre le monde Flaash avant le produit.

Doit :

- montrer la présence ;
- faire sentir la soirée ;
- utiliser une phrase-monde forte ;
- garder le téléphone absent ou secondaire ;
- orienter vers l'action.

Ne doit pas :

- montrer une app ;
- expliquer tout le parcours ;
- ressembler à une bannière de logiciel ;
- être trop stock ou trop luxe.

## 7. Sections narratives

Rôle : transformer la fonctionnalité en rituel.

Structure :

1. Scannez ;
2. Capturez ;
3. Découvrez ensemble ;
4. Pendant la soirée ;
5. Puis la soirée revient.

Règles :

- une image = un rôle ;
- un titre = une tension ;
- un bloc texte = une preuve ;
- pas de features en vrac ;
- le téléphone reste secondaire.

## 8. Pricing

Rôle : rassurer et convertir.

Règles :

- prix clairs ;
- pas de jargon de plan SaaS ;
- pas de pression artificielle ;
- expliquer selon taille d'événement ;
- garder le rituel en toile de fond.

Bon ton :

- Un prix par événement.
- Choisissez selon votre nombre d'invités.
- Export inclus.

Mauvais ton :

- Scalez votre expérience.
- Optimisez votre collecte.
- Plan recommandé pour utilisateurs avancés.

## 9. FAQ

Rôle : lever les doutes sans affaiblir la marque.

Règles :

- réponse directe d'abord ;
- langage humain ;
- aucune technicité inutile ;
- confidentialité et simplicité clairement expliquées ;
- pas de storytelling flou.

## 10. CTA final

Rôle : transformer l'envie en action.

Règles :

- revenir à la phrase-monde ;
- CTA shutter red ;
- promesse courte ;
- aucune nouvelle fonctionnalité ;
- pas de pression agressive.

Exemples :

- Créer un événement
- Préparer le reveal
- Lancer votre soirée Flaash

## 11. Footer

Rôle : clôturer proprement.

Règles :

- sobre ;
- utile ;
- légal clair ;
- contact visible ;
- pas de slogans secondaires en surnombre.

## 12. Posts Instagram

Rôle : faire reconnaître Flaash hors landing.

Règles :

- une image forte ;
- une phrase courte ;
- un distinctive asset ;
- tension lisible sans carrousel ;
- pas de démo produit frontale.

Formats :

- image + line ;
- crop détail QR ;
- reveal moment ;
- avant/après ;
- photo cachée.

## 13. Carousels

Rôle : raconter une mini-séquence.

Structure recommandée :

1. tension ;
2. QR ;
3. capture ;
4. attente ;
5. reveal ;
6. galerie ;
7. CTA.

Règles :

- chaque slide a une seule idée ;
- phrases très courtes ;
- répétition visuelle du crème, Ink, rouge ;
- pas de texte dense ;
- pas de tutoriel plat.

## 14. Stories

Rôle : créer un geste immédiat.

Formats :

- teaser reveal ;
- QR card ;
- compte à rebours ;
- photo cachée ;
- vote “avant/après reveal” ;
- coulisse de soirée.

Règles :

- 9:16 lisible ;
- phrase en moins de 8 mots si possible ;
- CTA simple ;
- pas de surcharge graphique.

## 15. Screenshots produit

Rôle : prouver que le produit existe et reste simple.

Règles :

- utiliser seulement de vraies interfaces validées ;
- jamais de fake UI ;
- écran secondaire dans le lifestyle ;
- lisibilité contrôlée ;
- aucun screenshot sans contexte émotionnel si le support est campagne.

## 16. Page invité

Rôle : faire participer sans sortir de la soirée.

Règles :

- instructions courtes ;
- bouton shutter red mémorable ;
- compteur de poses clair ;
- feedback rapide ;
- photos cachées expliquées simplement ;
- pas de jargon upload.

Microcopy :

- Prenez une photo.
- Elle attendra le reveal.
- Encore 6 poses.
- Revenez à la soirée.

## 17. Galerie

Rôle : recomposer la soirée.

Règles :

- album vivant, pas dossier ;
- images généreuses ;
- provenance invité si utile ;
- diversité des regards ;
- export rassurant mais secondaire ;
- ambiance reveal cohérente.

## 18. Reveal screen

Rôle : moment de marque principal.

Règles :

- mise en scène courte ;
- fond Ink possible ;
- typo émotionnelle contrôlée ;
- pas de théâtre excessif ;
- transition lisible ;
- sentiment de photos développées, pas simplement débloquées.

Phrases :

- Puis la soirée revient.
- Le reveal commence.
- Les souvenirs sont prêts.
- Tous les regards s'ouvrent.

## 19. QR card imprimée

Rôle : point d'entrée physique.

Règles :

- scannabilité prioritaire ;
- crème, Ink, rouge en signal discret ;
- instructions minimales ;
- phrase courte possible ;
- pas de décor qui réduit le QR ;
- premium accessible, pas papeterie luxe.

Microcopy :

- Scannez. Capturez. Revenez à la soirée.
- Les photos se découvriront plus tard.
- Un QR. Des regards. Un reveal.

## 20. Emails

Rôle : confirmer et guider.

Règles :

- objet clair ;
- une action principale ;
- pas de newsletter déguisée ;
- ton rassurant ;
- rituel rappelé brièvement.

Exemples :

- Votre QR code est prêt.
- Le reveal peut commencer.
- Vos souvenirs sont prêts à télécharger.

## 21. Dashboard organisateur

Rôle : contrôle calme.

Règles :

- vocabulaire événementiel ;
- états clairs ;
- actions précises ;
- pas de back-office froid ;
- ne jamais modifier la logique métier pour un effet de marque.

Microcopy :

- 42 photos attendent le reveal.
- Ouvrir la galerie maintenant.
- Exporter les souvenirs.
- QR prêt à partager.

## 22. Checklist finale

Avant d'intégrer une image, une section, une campagne ou une microcopy, vérifier :

- Est-ce que ça renforce le rituel ?
- Est-ce que ça ressemble à Flaash ?
- Est-ce que c'est clair sans explication longue ?
- Est-ce que c'est mémorable ?
- Est-ce que c'est premium sans être froid ?
- Est-ce que c'est social sans être bruyant ?
- Est-ce que c'est analogique sans être vintage cosplay ?
- Est-ce que le produit est compris ?
- Est-ce que le nom Flaash ressort plus fort après cette décision ?

Si la réponse est non sur le rituel ou la clarté, la décision est refusée.
