# Flaash brand voice

Statut : règles de voix, microcopy et ton pour Flaash.

Direction : **Analog Social Premium**.

## 1. Principe central

Flaash parle comme une marque qui comprend les soirées, pas comme une app qui explique ses fonctionnalités.

Vérité :

> Les gens ne veulent plus transformer chaque soirée en contenu en temps réel. Ils veulent d'abord la vivre, puis la redécouvrir ensemble.

Phrase-monde :

> La soirée se vit maintenant. Les souvenirs se découvrent plus tard.

Doctrine :

- Flaash ne vend pas des photos.
- Flaash vend le retour d'une soirée.
- Flaash ne documente pas parfaitement.
- Flaash laisse les vrais regards revenir.
- Flaash ne demande pas aux invités de gérer.
- Flaash transforme un geste simple en mémoire collective.
- Flaash n'est pas une app de plus.
- Flaash est un rituel social.

## 2. Personnalité de la voix

La voix Flaash est :

- courte ;
- sûre ;
- humaine ;
- chaleureuse ;
- directe ;
- premium accessible ;
- légèrement nostalgique ;
- jamais pompeuse ;
- jamais SaaS ;
- jamais technique en premier.

Elle doit donner le sentiment que Flaash sait exactement ce qu'il fait.

## 3. Rythme des phrases

Rythme recommandé :

- phrases courtes ;
- verbes concrets ;
- peu d'adjectifs ;
- tension claire ;
- une idée par phrase ;
- respiration entre émotion et preuve.

Structure utile :

1. phrase-monde ;
2. preuve simple ;
3. action.

Exemple :

> Les photos attendent. La soirée, non.  
> Vos invités scannent, capturent, puis reviennent au moment.  
> Vous choisissez quand la galerie s'ouvre.

## 4. Niveau de langage

Flaash parle en français naturel, contemporain, premium sans froideur.

À utiliser :

- vous ;
- vos invités ;
- soirée ;
- événement ;
- regards ;
- souvenirs ;
- reveal ;
- galerie ;
- QR ;
- capture ;
- photo ;
- moment ;
- ensemble.

À éviter :

- jargon marketing ;
- jargon SaaS ;
- superlatifs vagues ;
- luxe distant ;
- promesses émotionnelles génériques.

## 6. Mots et formulations interdits

Interdits :

- solution digitale innovante ;
- optimisez la collecte de photos ;
- centralisez vos souvenirs ;
- plateforme événementielle ;
- expérience utilisateur fluide ;
- créez des moments inoubliables ;
- digitalisez votre événement ;
- outil collaboratif ;
- interface intuitive ;
- solution clé en main ;
- gestion de contenu événementiel ;
- album photo augmenté.

Pourquoi :

- trop générique ;
- trop SaaS ;
- trop technique ;
- utilisable par n'importe quelle app ;
- ne porte pas le rituel Flaash ;
- ne donne aucune image mentale.

Règle : si une phrase pourrait être utilisée par n'importe quelle app événementielle, elle n'est pas assez Flaash.

## 7. Ton landing

Objectif : faire ressentir le rituel avant de détailler les fonctionnalités.

Priorités :

1. émotion ;
2. tension culturelle ;
3. simplicité ;
4. preuve produit ;
5. action.

Ton :

- éditorial ;
- direct ;
- imagé mais clair ;
- jamais abstrait ;
- jamais corporate.

Exemples :

- La soirée se vit maintenant. Les souvenirs se découvrent plus tard.
- Vos invités capturent les moments vrais. Vous choisissez quand ils reviennent.
- Un QR code posé sur la table. Des regards qui se retrouvent plus tard.
- Pendant la soirée, personne ne doit gérer l'album.
- Puis la soirée revient.

## 8. Ton pricing

Objectif : rassurer sans casser la magie.

Le pricing doit être :

- clair ;
- honnête ;
- direct ;
- sans agressivité commerciale ;
- sans jargon de plan SaaS.

À dire :

- Un prix par événement.
- Tout ce qu'il faut pour faire participer vos invités.
- Choisissez selon la taille de votre soirée.
- Export inclus.
- Aucun abonnement.

À éviter :

- plan le plus populaire surjoué ;
- croissance, scale, upgrade ;
- features en avalanche ;
- pression FOMO artificielle.

## 9. Ton FAQ

Objectif : répondre simplement aux peurs.

Règles :

- réponse courte ;
- commencer par la réponse directe ;
- expliquer juste assez ;
- ne pas survendre ;
- rester rassurant.

Exemple :

> Non. Vos invités scannent le QR code et prennent leurs photos depuis leur navigateur. Rien à installer.

## 10. Ton CTA

CTA principal :

- Créer un événement
- Lancer le reveal
- Prendre une photo
- Voir la galerie
- Télécharger les souvenirs

CTA secondaire :

- Voir comment ça marche
- Découvrir le rituel
- Préparer le QR
- Revenir à la soirée

À éviter :

- Commencer maintenant avec notre solution
- Optimiser mon événement
- Démarrer l'expérience
- En savoir plus sur la plateforme

## 11. Ton interface invité

Objectif : guider sans prendre la place de la soirée.

Principes :

- très court ;
- rassurant ;
- orienté geste ;
- pas de jargon ;
- pas d'explication longue.

Exemples :

- Scannez. Capturez. Revenez à la soirée.
- Il vous reste 8 poses.
- Photo envoyée.
- Elle apparaîtra au reveal.
- Plus de poses pour l'instant.
- La galerie s'ouvrira au moment choisi.

## 12. Ton dashboard organisateur

Objectif : donner du contrôle sans devenir back-office froid.

Principes :

- clair ;
- calme ;
- précis ;
- orienté événement ;
- fonctionnel sans jargon.

Exemples :

- Votre événement est prêt.
- QR code prêt à partager.
- 42 photos attendent le reveal.
- Ouvrir la galerie maintenant.
- Télécharger tous les souvenirs.
- Masquer cette photo.

## 13. Ton email transactionnel

Objectif : rassurer, confirmer, guider.

Principes :

- objet court ;
- première phrase utile ;
- un seul CTA principal ;
- chaleur sobre ;
- pas de marketing inutile.

Exemples d'objets :

- Votre événement Flaash est prêt
- Votre QR code est prêt
- Le reveal peut commencer
- Vos souvenirs sont prêts à télécharger

Exemple de corps :

> Votre événement est prêt.  
> Partagez le QR code avec vos invités. Ils pourront capturer la soirée sans installer d'app.  
> La galerie s'ouvrira au moment choisi.

## 14. Ton posts sociaux

Objectif : porter une tension mémorable.

Formats :

- phrase courte ;
- scène claire ;
- tension avant/après ;
- rituel visible ;
- pas d'explication produit longue.

Exemples :

- Les photos attendent. La soirée, non.
- Une soirée. Tous les regards.
- Le reveal commence.
- Ce que les invités ont vu.
- Avant le reveal.
- Après le reveal.

## 15. Ton captions

Règles :

- 1 à 3 phrases ;
- une tension ;
- une preuve ;
- un CTA si nécessaire.

Exemples :

> Tout le monde a vu une soirée différente. Flaash les réunit au reveal.

> Un QR sur la table. Des photos cachées. Un moment pour tout revoir ensemble.

> Les invités capturent. Vous révélez.

## 16. Ton microcopy

Microcopy Flaash :

- Photo envoyée.
- Elle attend le reveal.
- Encore 5 poses.
- Le reveal n'a pas encore commencé.
- Galerie privée.
- Export prêt.
- QR prêt à partager.
- Aucun compte invité.
- Rien à installer.

Microcopy à éviter :

- Upload successful.
- Asset processed.
- User limit exceeded.
- Content moderation action.
- Event media repository.
- Gallery access pending.

- Les photos attendent. La soirée, non.

- Vivez la soirée. Flaash s'occupe du retour.
- Les invités capturent. Vous révélez.

- Une soirée. Tous les regards. Un moment pour les revoir.
- Vos invités voient ce que vous ne verrez jamais seul.

- Le lendemain, la soirée revient.

## 18. Phrases interdites et raisons

| Phrase | Pourquoi c'est interdit |
|---|---|
| Solution digitale innovante | Jargon vide, aucun rituel |
| Optimisez la collecte de photos | Froid, administratif, SaaS |
| Centralisez vos souvenirs | Fonctionnel mais générique, pas assez Flaash |
| Plateforme événementielle | Trop large, trop corporate |
| Expérience utilisateur fluide | Parle du produit, pas du moment |
| Créez des moments inoubliables | Cliché événementiel |
| Digitalisez votre événement | Froid, daté, transformation digitale |
| Gérez vos médias facilement | Back-office, pas mémoire |
| La meilleure solution photo | Comparatif générique |

## 19. Test final d'une phrase

Avant validation, demander :

1. Est-ce court ?
2. Est-ce clair ?
3. Est-ce humain ?
4. Est-ce propre à Flaash ?
5. Est-ce lié au rituel ?
6. Est-ce que la phrase crée une image mentale ?
7. Est-ce que la phrase serait mauvaise dans une app SaaS générique ?

Si la réponse 7 est non, la phrase est probablement trop générique.
