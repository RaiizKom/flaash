# Flaash visual system

Statut : système visuel de marque pour la direction **Flaash — Analog Social Premium**.

Ce document définit comment reconnaître Flaash sans lire le logo. Il complète `DA_VALIDATED.md`, `BRAND_UNIVERSE.md`, `STRATEGIC_AUDIT_APPENDIX.md`, `IMAGE_ASSET_MAP.md` et `IMAGE_SHOTLIST.md`.

## 1. Essence visuelle

Flaash doit ressembler à un rituel social contemporain :

1. la soirée se vit ;
2. un geste court capture un regard ;
3. les photos attendent ;
4. le reveal fait revenir l'événement ;
5. la galerie devient une mémoire collective.

La marque ne vend pas une application photo. Elle rend visible un comportement : **vivre maintenant, redécouvrir ensemble plus tard**.

Visuellement, Flaash est :

- chaleureux, mais jamais mou ;
- premium, mais jamais distant ;
- analogique, mais jamais nostalgique au premier degré ;
- social, mais jamais bruyant ;
- digital, mais jamais SaaS ;
- simple, mais jamais générique.

## 2. Émotion centrale

L'émotion centrale est le retour d'une soirée.

Une image Flaash doit faire sentir :

- la présence pendant l'événement ;
- la complicité entre invités ;
- la valeur de l'attente ;
- la surprise du reveal ;
- la mémoire qui revient par fragments imparfaits.

La bonne émotion n'est pas « des gens utilisent une app ». C'est : **des gens vivent quelque chose qu'ils retrouveront plus tard ensemble**.

## 3. Ennemi de marque

L'ennemi visuel de Flaash est la documentation qui mange le moment.

À éviter :

- téléphone héros ;
- interface trop démonstrative ;
- QR code traité comme une publicité ;
- scène où les personnes regardent un écran au lieu de se regarder ;
- galerie représentée comme un dossier de fichiers ;
- luxe froid ;
- mariage parfait et distant ;
- rendu SaaS ;
- stock photo ;
- nostalgie décorative.

## 4. Distinctive assets

Les distinctive assets Flaash doivent revenir sur tous les supports.

| Asset | Rôle |
|---|---|
| Fond paper cream | Base chaleureuse, respirante, premium accessible |
| Ink | Structure, contraste, scènes nocturnes, reveal |
| Shutter red | Signal d'action et de déclenchement |
| Grain 35mm léger | Texture émotionnelle de mémoire |
| QR card | Point d'entrée physique du rituel |
| Bouton shutter red | Geste de participation |
| Compteur de poses | Pellicule collective, rareté légère |
| Photos cachées | Attente et désir |
| Reveal | Moment de marque principal |
| Galerie partagée | Mémoire collective recomposée |

## 5. Rôle du shutter red

Le shutter red est une couleur d'action, pas une décoration.

Il sert à :

- créer un événement ;
- scanner ou inviter à participer ;
- déclencher une photo ;
- signaler un état actif ;
- marquer un moment clé du rituel.

Il ne sert pas à :

- remplir des fonds entiers sans raison ;
- décorer des titres ;
- signaler une erreur ;
- attirer l'attention sur un élément secondaire ;
- remplacer la hiérarchie visuelle.

Règle : si le rouge n'aide pas à agir, déclencher ou révéler, il doit disparaître.

## 6. Rôle du grain 35mm

Le grain sert à rappeler la mémoire, l'imperfection et l'attente. Il n'est pas un filtre rétro.

Usage correct :

- grain léger ;
- texture visible mais discrète ;
- peau naturelle ;
- noirs lisibles ;
- compression web propre ;
- sensation de souvenir réel.

Usage interdit :

- grain lourd qui salit les visages ;
- fausse date imprimée ;
- rayures systématiques ;
- light leaks gratuits ;
- rendu vintage cosplay ;
- image artificiellement floue pour masquer l'IA.

## 7. Rôle de la QR card

La QR card est un objet social. Elle signale qu'une expérience existe dans le monde réel.

Elle doit :

- être visible quand le scan est le sujet ;
- rester intégrée à la table, à l'entrée ou à un support d'événement ;
- sembler posée naturellement ;
- être désirable sans devenir précieuse ;
- rester scannable dans le produit réel.

Elle ne doit pas :

- être centrée comme une fiche produit ;
- occuper toute l'image ;
- flotter en démo publicitaire ;
- être entourée de luxe décoratif ;
- contenir un faux QR utilisé comme QR final.

## 8. Rôle du bouton rouge

Le bouton rouge est le déclencheur mémorable de Flaash.

Il évoque :

- l'appareil photo ;
- le geste court ;
- la participation ;
- le passage d'un moment vécu à une mémoire enregistrée.

Il doit être tactile, lisible, généreux et rare.

Il ne doit pas devenir un motif décoratif répété partout.

## 9. Rôle du téléphone

Le téléphone est un outil de passage. Il n'est jamais le héros.

Règles :

- présence faible à moyenne selon la scène ;
- écran flou, sombre ou abstrait ;
- pas de fausse interface lisible ;
- pas de texte inventé ;
- pas de regard publicitaire vers l'app ;
- geste naturel, court, périphérique.

Si l'image reste forte quand le téléphone est masqué, elle est probablement juste.

## 10. Rôle du reveal

Le reveal est le moment de marque le plus important.

Il doit exprimer :

- la récompense différée ;
- la mémoire collective ;
- la surprise intime ;
- les regards qui reviennent ;
- la soirée qui se recompose.

Le reveal n'est pas un simple écran ouvert. C'est **le moment où l'événement revient**.

## 12. Règles de photographie

Une photo Flaash doit ressembler à un souvenir éditorial pris depuis l'intérieur de la soirée.

Principes :

- point de vue d'invité ;
- scène réellement habitée ;
- interaction humaine avant produit ;
- cadrage légèrement imparfait ;
- mouvement crédible ;
- chaleur sans filtre orange ;
- flash direct doux ou lumière mixte réaliste ;
- grain léger ;
- diversité d'événements premium accessibles.

À refuser :

- regard caméra trop publicitaire ;
- sourire de banque d'images ;
- décor de mariage luxe dominant ;
- smartphone centré ;
- faux écran ;
- composition trop propre ;
- rendu IA visible.

## 13. Règles de composition

La composition Flaash doit avoir une hiérarchie claire.

Ordre de lecture recommandé :

1. émotion humaine ;
2. contexte d'événement ;
3. geste produit ;
4. distinctive asset ;
5. détail de texture.

Règles :

- les personnes priment sur les objets ;
- les objets produit sont lisibles mais secondaires ;
- les zones de texte restent calmes sans paraître vides ;
- le cadrage mobile ne coupe pas l'action principale ;
- l'asymétrie est préférable à la symétrie publicitaire ;
- une image doit pouvoir être comprise en moins de deux secondes.

## 14. Règles de lumière

La lumière Flaash doit être crédible et habitée.

Sources acceptées :

- lumière de table ;
- flash doux ;
- fenêtre en lendemain de soirée ;
- lumière chaude d'intérieur ;
- ombres naturelles ;
- contraste nocturne lisible.

À éviter :

- orange uniforme ;
- néon nightclub générique ;
- peau plastique ;
- éclairage studio produit ;
- noir bouché ;
- ambiance luxe froide.

## 15. Règles de texture

La texture doit soutenir le souvenir.

Accepté :

- grain 35mm fin ;
- légère halation ;
- mouvement discret ;
- matière de table, verre, papier, peau, tissu ;
- imperfections crédibles.

Refusé :

- sur-texture artificielle ;
- flou généralisé ;
- bruit numérique ;
- accessoires rétro ajoutés pour faire vintage ;
- rayures ou poussières systématiques.

## 16. Règles de lieux

Lieux Flaash :

- appartement de soirée ;
- table vivante ;
- jardin privé ;
- salle contemporaine accessible ;
- terrasse ;
- lieu de fête sobre ;
- lendemain dans un salon ou autour d'une table ;
- espace événementiel premium mais non ostentatoire.

Lieux à éviter :

- palace froid ;
- ballroom luxueuse dominante ;
- bureau corporate ;
- nightclub générique ;
- plage/surf/travel ;
- studio photo blanc ;
- décor qui ne raconte plus l'événement.

## 17. Règles de casting

Casting :

- adultes ;
- groupes de 2 à 6 personnes ;
- expressions naturelles ;
- diversité d'âges adultes, carnations, styles et relations ;
- présence sociale crédible ;
- personnes absorbées par les autres, pas par la caméra.

À éviter :

- modèles trop posés ;
- influenceur face caméra ;
- casting mariage luxe uniforme ;
- expressions exagérées ;
- regards collectifs vers l'écran comme une pub d'app.

## 18. Règles de stylisme

Stylisme :

- élégant accessible ;
- vêtements de soirée réels ;
- matières naturelles ;
- couleurs crème, noir, brun, amber, forest, touches red ;
- détails personnels crédibles.

À éviter :

- mode comme sujet principal ;
- looks trop éditoriaux ;
- streetwear extrême ;
- costumes uniformes ;
- dorures et fleurs blanches comme code dominant ;
- accessoires absurdes sans lien rituel.

## 19. Règles d'interface

L'interface Flaash doit s'effacer après avoir rendu le geste possible.

Règles :

- CTA clair ;
- bouton rouge réservé aux actions importantes ;
- compteur lisible ;
- états simples ;
- textes courts ;
- focus visible ;
- mobile-first ;
- pas de complexité SaaS ;
- pas d'interface démonstrative dans les images.

## 20. Règles pour les images IA

Une image IA Flaash est acceptable uniquement si elle paraît photographique, plausible et utile au rituel.

Contrôles obligatoires :

- mains ;
- doigts ;
- visages ;
- regards ;
- reflets ;
- téléphone ;
- QR ;
- texte lisible ;
- logos ;
- compression ;
- crop mobile ;
- cohérence corpus.

Tout artefact visible bloque l'intégration.

## 21. Règle du hook contrôlé

Flaash peut avoir un hook visuel légèrement inattendu, mais jamais gratuit.

Un détail farfelu est accepté uniquement s'il renforce le rituel Flaash.

Hooks acceptables :

- QR card posée comme un objet social sur une table vivante ;
- main qui scanne depuis un angle légèrement imparfait ;
- bouton shutter red très mémorable ;
- photos cachées avant l'heure ;
- reveal time ;
- galerie qui revient comme une mémoire collective ;
- compteur de poses restantes ;
- phrase courte qui frappe.

Hooks refusés :

- absurdité mode sans lien produit ;
- poses extrêmes ;
- gens suspendus ;
- image waouh mais incompréhensible ;
- téléphone héros ;
- scène qui ne parle plus d'événement ;
- QR en démo publicitaire.

Règle finale : le hook doit rendre le rituel plus clair, pas seulement l'image plus spectaculaire.

## 22. Checklist de validation

Une image Flaash est validée seulement si elle coche :

- émotion claire ;
- rôle produit lisible ;
- téléphone secondaire ;
- QR naturel si présent ;
- lumière crédible ;
- grain léger ;
- événement crédible ;
- pas de rendu SaaS ;
- pas de luxe froid ;
- pas de stock photo ;
- pas d'IA visible ;
- pas d'objet décoratif gratuit.

Si un seul point critique échoue, l'image doit être retravaillée ou rejetée.
